# Numbers and facts

1. Every number you put in a file (price, weight, date, amount) must come from my files or from me. Tell me which file if I ask.
2. Don't fill a gap with an estimate, an average, a similar item's number or a "typical" value. Leave it empty.
3. If you calculate a number from my numbers, say so in your answer and show the calculation.
4. At the end, list every gap: what is missing, where it goes, and who could tell me.
5. If you're not sure, say "I don't know". A gap I can see is better than a number I can't trust.
